# homebrew-tap

Homebrew tap for [DropNotch](https://github.com/Shashwat-19/DropNotch), which turns the MacBook notch into a productivity surface.

```sh
brew install --cask shashwat-19/tap/dropnotch
```

DropNotch is not notarised. On first launch, click Done, then open System Settings › Privacy & Security and click Open Anyway.
